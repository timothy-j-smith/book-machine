# The blank book

This is not a novel. It is the **master blank**: Today, chapters, vault, and back office already tabbed, with no story in them.

The script and the partner **copy** this folder when you start a book. They name the copy. That copy is the novel.

Do not write chapters here. Do not open this as a workspace. This folder is locked on purpose. To change the machine itself (rare), unlock it, edit, lock it again.
