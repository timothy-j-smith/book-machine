The Book Machine

How this works. Updated October 18, 2026. One writing system. Dump, study passages, and where the guides live.

Where you operate: not the file tree. Run ~/Writing/book-machine/scripts/open-the-desk.sh. A page opens — Continue, start a novel, your books. That is the desk. Cursor is the chair. This page is the map.
The one-sentence rule You have one writing system. You sit with one novel folder at a time. Everything else is an attic. You may visit an attic. You do not write new pages there.

1. The three pieces (this is the whole machine)

“Template” was the old word. It sounded like you should customize a new system for every book. You should not.

1. The method — writing-tools/
How we interview, sit down, and file. Already exists. Opened beside a novel. Never copied into a novel.
2. The blank book — blank-book/
Master blank with the tabs already there and no story. Locked. Do not write in it. Do not open it. Copied and named — that copy is the book.
3. The novel — novels/the-title/
Today, chapters, vault, back office. This is the only folder you live in for that story.

You do not make a fourth piece. You do not build a new workspace system for each book.

When we change the machine later (not yet):
A change to writing-tools is live for every novel the next time you sit down. A change to the blank book only affects novels created after that. If a new tab or default should travel with new books, update both (unlock, edit, lock). Write and test first. Do not redesign in the same week you are trying to draft.

1A. Folders vs a workspace

A folder is a box on the disk. The three pieces above are folders.

A workspace is a small file named OPEN-ME.code-workspace. It is a seat assignment. It tells Cursor: show me these folders in one window.

Those three folders are not three workspaces. You do not glue three workspaces together.

When you write, you open one workspace file. It is multi-root. It holds two folders:

1. The method (writing-tools/) — the same folder every time. Not copied. Not a new workspace.
2. This novel (novels/the-title/) — whichever book you opened.
ONE window = ONE OPEN-ME.code-workspace
↓
folder: writing-tools (always the same)
+
folder: novels/the-title (this book only)

The blank book is never a workspace. It is locked. Twenty ideas means twenty folders on the shelf — not twenty writing systems, and not all twenty open at once. The script or the partner writes the OPEN-ME file. You double-click it.

  1. Factory — book-machine/OPEN-ME — method + the whole novels shelf. Start a book, see what exists.
  2. Tuesday desk — novels/the-title/OPEN-ME — method + one book.

2. Who does what

2.1 Already exists — do not recreate

  1. ~/Writing/book-machine/ — the factory
  2. writing-tools/ — the method
  3. blank-book/ — the blank book (locked master)
  4. novels/ — the shelf
  5. scripts/new-novel.sh — the photocopier

2.2 You manage

  1. Open the right desk — that novel’s OPEN-ME.code-workspace
  2. Talk and write
  3. Say the plain sentences: Vault this. I’m done for today. Continuing [title].
  4. Leave attics alone once they are snapshotted

You do not patrol the back office. You do not rebuild ten documents before you are allowed to write.

2.3 The partner or the script creates

  1. A new novel folder (named copy of the blank book)
  2. That novel’s OPEN-ME.code-workspace
  3. Interview notes, thin canon, thin map, and TODAY.md
  4. Chapter files when you write
  5. Vault, story state, session notes, and a new Today when you stand up

No Terminal? Say: New novel. Interview me. Title: _____

4. The three sittings (same folders, different first hour)

The folders do not change. What you say first changes.

4.1 Starting new — nothing written

  1. Create the novel folder (script or partner).
  2. Open that book’s OPEN-ME.
  3. Say Interview me.
  4. Talk. Messy is fine.
  5. Write when you can see a scene. Do not wait for ten documents to be “done.”
  6. Partner keeps the back office.

4.2 In motion — chapter 2, 3, or 4

You already have a novel folder. You do not create a new one.

  1. Open that same OPEN-ME.
  2. Read TODAY.md.
  3. Say Continuing [title].
  4. Talk, write, or look.
  5. Partner updates only what the story moved.
  6. A week away is not starting over. Today is the memory.

If the book still lives in an attic, copy it into novels/the-title/ first. Leave the attic untouched. Then the list above.

4.3 The draft exists — now you are editing

Still the same novel folder. Still the same OPEN-ME.

  1. Open that book.
  2. Say This draft needs work. Intake it.
  3. The pages are the book. You do not fill a hub to make the draft legal.
  4. You get a short list of what matters, with places in the book.
  5. Today becomes one fight.
  6. You edit. Partner files the ripples.

Adding chapters is “continuing.” Hating the prose is this rewrite, with one fight: the sentences.

4.4 The dump — every sitting, one pile

The dump is how raw material arrives. It is not a fourth way to write.

  1. One dump per novel: novels/the-title/dump/.
  2. Throw in prose, notes, scraps, half-outlines. You do not sort them.
  3. The partner files what became a decision: chapters only when you say it is the book, canon, the map, or the vault.
  4. Say Dump this when you only need the pile caught.

dump/study/ is for short passages from novels you own. Private education. The GitHub repo is private, so those snippets may live there. Label them with the author and the book. They are teachers. They are not your chapters.

5. What you open on a Tuesday

  1. Write a book already in the machine — that book’s OPEN-ME.code-workspace
  2. Start a new book — factory ~/Writing/book-machine/OPEN-ME.code-workspace, create the novel, then switch to that book’s OPEN-ME
  3. Mine an attic — this Desktop pile, or later Walk This Way, in a separate window. Copy out. Do not move in.

If the folder list looks like the old ten-file house, you are in an attic.

6. What you say

  1. New novel. Interview me. Title: _____
  2. Continuing [title].
  3. This draft needs work. Intake it.
  4. Vault this.
  5. Park that for book two.
  6. I’m done for today.
  7. Dump this.
  8. This is study. Name the author and the book.

7. Attics

  1. This folder — Cursor writing template on the Desktop. Father of Mine, Qitat, dumps. GitHub snapshot. Do not start novels in writing-data/.
  2. Walk This Way’s workspace — older, larger, a book and an earlier system. Same recipe later: snapshot, leave, bring the book into the machine. Do not build a second machine inside it.
  3. Compass, HyperAgent, iCloud copies — visit. Do not live there.

When you let go of a large folder: copy the book out first. Keep the attic until the copy feels like the book.

8. What you never do again

  1. Build a new writing system because the last one felt messy.
  2. Write inside blank-book/.
  3. Copy the method into the novel.
  4. Keep ten documents in sync by hand.
  5. Start a new novel inside an attic.
  6. Open five old workspaces “just to be safe.”

9. If you get that lost feeling

  1. You are not starting over.
  2. Open ~/Writing/book-machine/ and this guide.
  3. If the book is already under novels/, open that OPEN-ME and read Today.
  4. If it is not, you are starting new — or bringing a book in from an attic.
  5. Do not create a new system.
