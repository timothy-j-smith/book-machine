# For the blank book

`blank-book/` is locked, so a book window cannot change it. When a sitting shows that every new novel should start with a different file, folder, or heading, add a line here. The attic unlocks the blank book, makes the change, locks it again, and crosses the line off.

One line each: the date, the novel it came from, what should change, and why.
