# The desk and the back office

The ten files were not a bad idea. They became a second job. This is the split.

## The desk (author)

| File | What it is |
|------|------------|
| `TODAY.md` | Where we left off. The one job for this sitting. Rewrite this every time you stand up. |
| `chapters/` | The novel you are writing now. One file per chapter. This is the only document that counts as the book. |
| `drafts/` | Frozen copies. `01/` is the first kept draft. The next number appears only when he says “keep this draft.” Older numbers stay. He opens one when a later pass went somewhere he does not want. |
| `VAULT.md` | Cuts, sparks, “maybe later.” Dated. Never lost in chat. |
| `dump/` | Raw pile. The author does not sort it. You file what became a decision. |
| `dump/study/` | Short passages from novels he owns. Private education. Allowed in the private repo. Teachers, not chapters. See `STUDY.md`. |
| The chat | Interview, trade the pen, argue, decide. |

Every Open Me writes the chapter to disk when you leave that page: another chapter, the notes, or out of the window. A pause in the middle of a sentence leaves the page alone. A new draft number still happens only when you say “keep this draft.”

## The back office (partner)

| File | What it is |
|------|------------|
| `CANON.md` | Bible + characters + world + rules. One living file. |
| `STORY-MAP.md` | Acts, titles, and the three-to-four-sentence beats. Outline and expanded outline were the same document wearing two hats. The board on the desk shows its Chapters section as one card per chapter and saves back into it. Keep each block's `- File:`, `- Does:`, `- Eyes:`, `- Where:`, `- Tension:` and `- Status:` lines so the board can read it. |
| `STORY-STATE.md` | What has happened, what is promised, what is open, what changed last sitting. |
| `WHO-KNOWS.md` | Which character knows which fact, as of which chapter. The partner keeps it after sittings. The Professor reads it before he takes the pen. Not a gate before Chapter 1. |
| `VOICE.md` | A short taste note, plus fingerprints taken from *his* pages when pages exist. |
| `INTERVIEW.md` | Raw capture. Evidence. Not homework. |
| `SESSION-NOTES/` | What used to be chat summaries. You write them. |
| `READS/` | Full reads of the story: cold reads, second passes, master's reads. See `READER.md`. Made the first time one is saved. |
| `SEE-WHAT-I-SEE/` | One file per pass the Professor wrote or edited: what changed, and why. Named by chapter and date. He asks for it and prints it. |
| `MANUSCRIPT.md` | Chapters stitched in order so he can read straight through. Never hand-synced by the author. |

A synopsis is a *view* you regenerate when he needs the whole shape for a pitch or a reread. It is not a third novel.

Series seeds (Book 2, Book 3) wait until something needs parking. Then create `series/` in that novel. Do not put empty series files in every book.

## The test

After a sitting where the story changed: did he write, or did he spend the hour making the map match? If it was the map, you failed the job.
